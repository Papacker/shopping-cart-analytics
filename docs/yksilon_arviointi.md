Arviointikriteerit jaotellaan ryhmätasoon ja yksilötasoon. Jokainen yksittäinen arviointikriteeri joko toteutuu tai ei toteudu, valinta on siinä suhteessa binäärinen. 
Arvioinnin kolme tasoa (1 < 3 < 5) rakentuvat toistensa päälle. Alemman tason kaikkien kriteerien on täytyttävä hyväksytysti ennen kuin ylempi taso saavutetaan.

# Yksilötaso

## Työpanos ja sitoutuminen projektiin 

Tässä osiossa keskitytään arvioimaan miten arvioit työtehtäviesi tuomia vastuita.

**TASO 1**

- [ ] Varmistat dokumentoidusti omien tehtäviesi suoritetuksi tulemisen. (työajanseuranta)
- [ ] Olet tarkastellut ryhmän työnjakoa dokumentoidusti. (suunnittelupalavereihin osallistuminen)
- [ ] Seuraat ohjeita ja sovittuja suunnitelmia dokumentoidusti. (sprintin taskit)


**TASO 3**

- [ ] Tarkastelet dokumentoiden omien työtehtäviesi suhdetta projektin tavoitteisiin. 
- [ ] Olet arvioinut ryhmän työnjakoa ja tasapuolisuutta dokumentoidusti. 
- [ ] Tarkastelet ryhmän jäsenten toimintaa ja keskustelet havainnoistasi. 

**TASO 5**

- [ ] Arvioit dokumentoidusti oman työtehtäväsi merkitystä projektin onnistumiselle. 
- [ ] Olet pyrkinyt edistämään työnjaon tasapuolisuutta dokumentoidusti. 
- [ ] Sisällytät hyviä käytänteitä toisten ryhmien toiminnasta oman ryhmäsi toimintaan. 

## Oman työn seuranta ja kehittäminen

Tässä osiossa keskitytään arvioimaan miten tuotat tietoa jäsentyneiden aika-arvioiden tekemiseen ja millaiseksi arvioit työsi arvon.

**TASO 1**

- [ ] Olet dokumentoinut käyttämäsi työajan projektissa.
- [ ] Olet dokumentoinut kehittämiseen kuluneen työajan
- [ ] Olet dokumentoinut yhteydenpitoon kuluneen työajan.

**TASO 3**

- [ ] Olet dokumentoidusti erotellut tehtävittäin käyttämäsi työajan.
- [ ] Olet jakanut dokumentoidusti työaikasi järjestelmällisesti projektin ajalle. 
- [ ] Olet arvioinut kuluneen työajan rahallista arvoa. 


**TASO 5**

- [ ] Olet dokumentoidusti erotellut jokaiseen iteraatioon käyttämäsi työajan.
- [ ] Olet dokumentoidusti arvioinut työajan rahallista arvoa jokaisessa iteraatiossa.
- [ ] Sovellat dokumentoidusti työajan seurantaa uusien tehtävien aika-arvioiden tekemisessä joka iteraatiossa.



## Reflektio- ja itseohjautuvuusosaaminen

Tässä osiossa keskitytään arvioimaan miten havainnoit työroolisi tuomia vastuita.

**TASO 1**

- [ ] Olet kuvannut sanallisesti työroolisi.
- [ ] Olet dokumentoidusti tarkastellut oman työroolisi tehtäviä, ja pohtinut mitä niihin kuuluu.

**TASO 3**

- [ ] Olet kuvannut dokumentoidusti miten työroolisi sijoittuu projektin toimintaan. 
- [ ] Olet dokumentoidusti pohtinut, mitä vastuita työrooli tuo ryhmän toiminnan näkökulmasta.

**TASO 5**

- [ ] Olet dokumentoidusti jäsentänyt tehtäväkuvaasi työroolin vastuiden ja projektiin sijoittumisen perusteella. 
- [ ] Olet dokumentoinut miten olet huomioinut vastuusi ryhmän toiminnassa omassa työssäsi.
- [ ] Olet dokumentoidusti arvioinut ryhmän työnjakoa ja tasapuolisuutta.
